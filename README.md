
# Startup Landing Page - Experiment 08

A responsive Startup Landing Page developed using HTML, CSS and AngularJS.

## Features
- Welcome message
- Display startup services
- Calculator
- Task Manager
- Add and Delete Tasks
- Comment Box
- Add and Delete Comments

## AngularJS Directives Used
- ng-app
- ng-controller
- ng-model
- ng-click
- ng-repeat

## Technologies Used
- HTML5
- CSS3
- AngularJS
- JavaScript

## How to Run
1. Open the folder in VS Code.
2. Open index.html.
3. Right-click and select Open with Live Server.
4. Internet connection is required for AngularJS CDN.

## Result
Successfully created a Startup Landing Page using AngularJS directives.
